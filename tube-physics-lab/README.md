# Tube Physics Lab

A lightweight React + TypeScript app for quick, first-order tube acoustics checks.

## Features

- Convert tube length to predicted resonant frequency for odd harmonics
- Estimate required tube length for a target frequency
- Includes a basic open-end correction from bore radius
- Shows nearest equal-tempered note and cents offset

## Run

1. Install dependencies at repository root:
   npm install
2. Start this app:
   npm run dev:tube

## Notes

This tool is intentionally simple for fast iteration before deeper simulation.
